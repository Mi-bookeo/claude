# Instrucciones para Claude

## Carrusel de Instagram

Si el usuario pide un **carrusel** (de Instagram, de la semana, de publicaciones u ofertas), aunque no diga nada más:

1. Lee primero `carrusel/README.md` y sigue sus pasos.
2. Usa la plantilla `carrusel/plantilla/generar.js` con los personajes, fuentes y logos del repo. No inventes otro diseño.
3. Saca los datos de las capturas o fotos que adjunte (foto, título, comercio, tipo, descuento, fecha de fin). Si falta algo imprescindible, pregúntalo.
4. Envíale los JPG y el pie de foto por el chat para descargar. **No subas las imágenes al repo.**
5. Sube solo `carrusel/estado.json` para que la rotación de personajes continúe.
